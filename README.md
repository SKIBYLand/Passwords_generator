# PasswordMe

PasswordMe — simple password generator and manager.

## Downloads
- Releases (recommended): 
- Direct (in-repo): `dist/Dmg_version/PasswordMe.dmg` (macOS DMG)

## macOS (DMG installer)
- The macOS installer is available as `dist/Dmg_version/PasswordMe.dmg`.
- To install: double-click the `.dmg` to mount it, then drag `PasswordMe.app` to `/Applications` or follow the on-screen installer.
- Important: on first run macOS may prompt you to enter your password to grant PasswordMe access to the Keychain — enter your password when prompted to allow Keychain access.

> ⚠️ Gatekeeper: The app may be blocked or warned about if it is not notarized. Use caution and only install if you trust the source.

## Verify checksum
- macOS / Linux: `shasum -a 256 dist/Dmg_version/PasswordMe.dmg`
